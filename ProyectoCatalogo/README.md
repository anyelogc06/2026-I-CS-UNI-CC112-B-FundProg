# PROYECTO: Catálogo de Medios Digitales

Bienvenido al repositorio oficial del **Catálogo de Medios Digitales**. Este sistema está diseñado para organizar, almacenar y administrar contenidos multimedia de forma eficiente.

---

## 📌 Objetivo Principal del Sistema

Desarrollar una plataforma robusta que permita el control total y la indexación de diferentes recursos digitales.

### Sistema de Gestión
> *Generar las clases y archivos necesarios para el almacenamiento y gestión de los datos registrados.*

---

## 🛠️ Tecnologías y Arquitectura

*   **Diseño de Clases:** Estructuración de objetos principales para modelar los medios digitales.
*   **Persistencia de Datos:** Creación de archivos y directorios locales para asegurar el almacenamiento de la información.
*   **Lógica de Negocio:** Componentes dedicados exclusivamente a la gestión, edición y filtrado de los registros.
